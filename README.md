🎩 TheHiddenWizard

✨ A Harry Potter-inspired project that brings the magic of invisibility to life using technology!

🌟 Overview
TheHiddenWizard is a fun and magical prototype inspired by the Invisibility Cloak from Harry Potter. Using a camera and display system, it creates the illusion of invisibility by blending objects seamlessly into their surroundings.

✨ Features
🔮 Real-time invisibility effect through background blending.
🪄 Simple yet powerful computer vision techniques with OpenCV.
⚡ Brings a touch of wizardry to the world of technology.

🛠️ Tech Stack
💻 Programming Language: Python
📚 Frameworks/Libraries: OpenCV
🎥 Hardware: Camera and display setup

🧙 How It Works
1️⃣ The camera captures the surrounding environment in real-time.
2️⃣ Using background subtraction and masking, the object is "invisibly" blended into the background.
3️⃣ The processed video feed is displayed, giving the illusion of invisibility!

🚀 Setup and Installation

1️⃣ Clone the repository:

git clone https://github.com/Nisarg7777/TheHiddenWizard.git  
cd TheHiddenWizard  

2️⃣ Install dependencies:

pip install -r requirements.txt  

3️⃣ Run the script:

python invisibility.py
